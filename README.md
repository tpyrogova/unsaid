# Unsaid

Бережный психологический разбор записи из личного дневника. Пользователь пишет текст как есть, а приложение показывает:

- **эмоции** и их интенсивность;
- **неудовлетворённые потребности**;
- **когнитивные искажения** в формате «цитата → переформулировка»;
- **повторяющиеся сценарии** поведения;
- **один мягкий вопрос** для саморефлексии.

Главный принцип: **наблюдения, а не диагнозы**. Каждый вывод опирается на дословную цитату из записи, поэтому всегда видно, откуда он взялся.

> Сейчас это фронтенд на моковых данных. Следующий этап: Cloudflare Worker с LLM-анализом.

## Стек

- [Vite](https://vite.dev) + React + TypeScript (strict)
- Tailwind CSS v4 (через `@tailwindcss/vite`)
- Деплой: Cloudflare Pages (`npm run build` → `dist/`)

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов + production-сборка в dist/
npm run lint     # oxlint
```

## Модель приватности

Дневник — один из самых чувствительных видов данных. План по этапам:

**Сейчас (MVP на моках)**
- Текст не уходит в сеть и не сохраняется: ни в `localStorage`, ни куда-либо ещё. Он живёт только в памяти вкладки.
- В репозитории только синтетические данные. Папка `private/`, файлы `.env*` и `.dev.vars` добавлены в `.gitignore`.

**Планируется**
- **Анализ без хранения на сервере.** Worker получает текст, вызывает модель и возвращает результат. Тело запроса не логируется и не сохраняется.
- **Шифрование истории в браузере.** Если появится история записей, она будет храниться локально в зашифрованном виде (Web Crypto API, AES-GCM, ключ выводится из пароля пользователя). На сервер не попадает ни текст, ни ключ.
- **Ключи только в секретах.** API-ключ модели хранится только в Cloudflare Secrets (`wrangler secret put`), в браузер он не попадает. Для локальной разработки используется `.dev.vars`, который исключён из git.
